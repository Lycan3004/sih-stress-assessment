# 🖥️ SIH Stress & Trauma Assessment — Frontend Client

The web frontend for the **Real-Time Stress & Trauma Assessment Platform**, built for victims seeking immediate psychological evaluation and crisis responders monitoring live distress incidents.

---

## 🚀 Features

- **🗣️ Real-Time Voice & Speech Input**:
  - **Live Transcription**: Uses the browser's Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`) to convert victim speech into text on the fly.
  - **Acoustic Audio Capture**: Simultaneously streams raw microphone input through the `MediaRecorder` API into a `.wav` blob for physical vocal tremor, pitch jitter, and energy analysis in the Python AI microservice.
- **🧠 Dynamic Crisis Counseling Chat**:
  - Interactive chat interface with real-time **SVI (Stress Vulnerability Index)** scores and risk indicators (`LOW`, `MODERATE`, `HIGH`, `CRITICAL`).
  - Empathy-driven responses generated by Google Gemini 3.6 Flash and situational crisis safety overrides.
- **📍 Emergency Geolocation Dispatch**:
  - Automatically requests browser geolocation (`navigator.geolocation`) on session initialization so responders receive precise GPS coordinates during critical threats.
- **📡 Live Incident Command Center (`/dashboard`)**:
  - Real-time updates via `Socket.io` client (`new_assessment` events).
  - Risk distribution analytics chart powered by `Recharts`.
  - Live incident feed table displaying user emails, timestamps, transcripts, and status badges.
- **🔐 Secure Authentication**:
  - Powered by Firebase Auth (`signInWithEmailAndPassword`, `createUserWithEmailAndPassword`).
  - Syncs authenticated users with PostgreSQL via Node.js Gateway.
  - Automatic role-based routing (Admin $\to$ Command Center, Victim $\to$ Assessment Portal).

## 🛠️ Tech Stack

- **Framework**: React 19 & TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Visualizations**: Recharts
- **Networking**: Axios, Socket.io-client
- **Authentication**: Firebase Client SDK

## ⚙️ Environment Variables

Create or configure `.env` in the `frontend/` directory:

```env

VITE_ADMIN_EMAIL="admin@sih.com"
```

## 🏃 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
# Running on http://localhost:5173
```

### 3. Build for Production
```bash
npm run build
```

## 🔗 Integrated Services

The frontend communicates with:
1. **AI Microservice**: `POST http://localhost:8000/api/analyze` (Multipart form-data: text + audio + history)
2. **Gateway API**: `POST http://localhost:4000/api/users/sync`, `POST/GET http://localhost:4000/api/assessments`
3. **Gateway WebSockets**: `ws://localhost:4000` (Subscribes to `new_assessment`)
